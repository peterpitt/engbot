# 日劇單字速記 (engbot)

一個手機優先的日文學習單頁網站，把「追劇時間」變成「聽力＋口說訓練時間」。
靈感來自常見的日劇學習攻略頁面風格；**所有單字、例句與內容皆為原創**，非複製任何付費課程內文。

## 功能
- **今日單字**：Day 1 共 **200 個單字**，依 10 大日劇日常情境分類（早晨起床、通勤、職場、吃飯、購物、情緒、戀愛、附和口頭禪、家事、時間約定），每字含假名、羅馬拼音、中文意思與口語例句。可切換羅馬拼音、遮住中文自測。
- **情境應用**：每個場景可「整段聽一次」或「整段變速跟讀」，像演對手戲。
- **速度練習（核心）**：每個單字／例句用固定節奏播放 —
  **1×（1 次）→ 1.5×（3 次）→ 2×（3 次）**，共 7 次。支援上一個／下一個、自動連播。
- **一小時計畫**：把每天一小時拆成 看單字 15′ / 情境跟讀 20′ / 變速狂練 15′ / 檢測複習 10′。
- **自我檢測**：隨機抽 10 題中文意思選擇，即時計分。
- 深／淺色主題、純前端、免後端。

## 語音
使用瀏覽器內建 `SpeechSynthesis`（Web Speech API）朗讀日文，不需任何 API 金鑰或網路。
需裝置有日文語音（手機/電腦的 Chrome、Safari 通常內建）。若沒有日文語音，頁面會提示。

## 檔案
- `index.html` — 介面與所有程式邏輯（CSS/JS 內嵌）
- `data.js` — 單字資料庫（想加 Day 2、Day 3 照格式往 `DAYS` 加即可）

## 使用
直接用瀏覽器開啟 `index.html` 即可，或丟到任何靜態主機（GitHub Pages 等）。

## 擴充：新增一天的單字
在 `data.js` 複製 `DAY1` 的結構改成 `DAY2`，再加進最後的 `const DAYS = [DAY1, DAY2];`。
每天一組 10 情境 × 20 字＝200 字即可維持節奏。
