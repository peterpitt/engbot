# 英語單字速記 (engbot)

一個手機優先的英語學習單頁網站：**20 天課程、每天 200 個情境單字（共 4000 字）**，
把「每天一小時」變成有效的聽力＋口說訓練。所有單字與例句皆為原創內容。

## 功能
- **20 天課程**：用 hero 下拉選單切換 Day 1～20，每天 200 字、10 大情境 × 20 字。
  - Day 1 日常問候・2 家庭人際・3 居家作息・4 飲食餐廳・5 購物金錢・6 工作辦公室・
    7 學校學習・8 旅行交通・9 健康身體・10 情緒感受・11 天氣自然・12 科技網路・
    13 城市公共場所・14 興趣休閒・15 電話溝通・16 服裝外表・17 社交約定・
    18 問題解決・19 意見討論・20 常用片語動詞與慣用語。
- **今日單字**：每字含單字／中文意思／英文例句＋翻譯，可切換「遮住中文」自測。
- **情境應用**：每個場景可「整段聽一次」或「整段變速跟讀」。
- **速度練習（核心）**：每個單字／例句用固定節奏播放 —
  **1×（1 次）→ 1.5×（3 次）→ 2×（3 次）**，共 7 次。支援上一個／下一個、自動連播。
- **一小時計畫**：看單字 15′／情境跟讀 20′／變速狂練 15′／檢測複習 10′。
- **自我檢測**：隨機抽 10 題中文意思選擇，即時計分。
- 深／淺色主題、純前端、免後端、免 API 金鑰。

## 語音
使用瀏覽器內建 `SpeechSynthesis`（Web Speech API）以 `en-US` 朗讀英文。
需裝置有英文語音（手機/電腦的 Chrome、Safari 通常內建）。

## 檔案
- `index.html` — 介面與所有程式邏輯（CSS/JS 內嵌），支援 20 天切換
- `data.js` — 單字資料庫（`DAYS` 陣列，每天一個 `addDay({...})`，約 333 KB）

## 使用
直接用瀏覽器開啟 `index.html` 即可，或丟到任何靜態主機（GitHub Pages 等）。

## 擴充
在 `data.js` 照既有 `addDay({ day, title, subtitle, scenarios:[...] })` 格式往下加即可，
`DAYS` 會在載入時自動依 `day` 排序。
